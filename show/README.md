# UE ITPS 本地关系浏览器

独立、只读地浏览 UE ITPS v4 SQLite 知识图谱。浏览器及其依赖均位于本目录，不导入或修改仓库中的 v1～v4 文件。

## 启动

双击 `start-local.cmd`，或在 PowerShell 中运行：

```powershell
cd E:\UE_ITPS\show
.\start-local.ps1
```

浏览器将打开 `http://localhost:4173`。首次进入后选择需要查看的 `.sqlite3` 数据库，例如 `LyraStarterGame.sqlite3`。

## 使用

1. 点击“打开数据库”并选择 v4 数据库。
2. 选择“单节点浏览”或“多节点关系”模式。
3. 搜索类、结构体、枚举、函数、变量或文件，并点击候选项。
4. 单节点模式可通过深度和节点上限控制局部关系范围。
5. 多节点模式可持续添加任意数量的关注节点，自动查询完整数据库并显示所有有效联通关系，包括替代路径和环路。
6. 可在关注节点栏移除节点、更新关系或清空选择。
7. 点击节点或关系查看源码证据；双击节点可切回该节点的单节点浏览。

数据库只读加载到当前浏览器内存，不上传，也不会被修改。多节点模式不使用深度、节点数量或关注节点数量上限；无法连接其他关注节点的节点仍会保留在画布中，并以虚线边框提示。大型结果会渐进绘制，避免长时间阻塞页面。

## 独立性

- 运行依赖固定在本目录的 `node_modules` 中。
- SQLite 读取引擎编译进本地页面脚本，不从网络加载运行库。
- 应用代码没有导入、调用或硬编码引用 `show` 以外的仓库文件。
- 数据库由用户通过页面文件选择器显式打开。
