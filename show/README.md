# UE ITPS 本地关系浏览器

独立、只读地浏览 UE ITPS 工程信息池 SQLite 快照。浏览器及其依赖均位于本目录，
不导入或修改项目工具池与信息池实现。

## 启动

双击 `start-local.cmd`，或在 PowerShell 中运行：

```powershell
cd E:\UE_ITPS\show
.\start-local.ps1
```

浏览器将打开 `http://localhost:4173`。首次进入后选择需要查看的 `.sqlite3` 数据库，例如 `LyraStarterGame.sqlite3`。

## 使用

1. 点击“打开数据库”，选择信息池 `snapshots/` 下的 SQLite 快照。
2. 选择“单节点浏览”或“多节点关系”模式。
3. 搜索类、结构体、枚举、函数、变量或文件，并点击候选项。
4. 单节点模式可通过深度和节点上限控制局部语义关系范围；类和结构体会自动聚合其成员关系。
5. 多节点模式可持续添加关注节点，自动显示关注节点之间确定性的最短语义路径。
6. 可在关注节点栏移除节点、更新关系或清空选择。
7. 类关系默认展开成员链路，以逐行显示源类、源方法、语义关系、目标方法、目标类及源码行；可随时收起到类级概览，双击节点可切回该节点的单节点浏览。

默认视图只使用调用、继承、类型使用、包含和回调等语义关系。声明、定义、成员归属和无法分类的原始引用仍保留在信息池中，但不会混入默认寻路。数据库只读加载到当前浏览器内存，不上传，也不会被修改；无法连接其他关注节点的节点仍会保留在画布中，并以虚线边框提示。

## 独立性

- 运行依赖固定在本目录的 `node_modules` 中。
- SQLite 读取引擎编译进本地页面脚本，不从网络加载运行库。
- 应用代码没有导入、调用或硬编码引用 `show` 以外的仓库文件。
- 数据库由用户通过页面文件选择器显式打开。
