# UE 文件知识图谱浏览器

该页面只在浏览器内存中读取第一阶段生成的 SQLite 文件，不上传也不修改图谱。

```powershell
cd show
npm install
npm run dev
```

打开页面后选择 `information_pool/build_file_graph.py` 生成的 `.sqlite3` 文件。默认从
`.uproject` 展开三层，可调整深度和节点上限，也可以搜索文件、模块或插件并重新聚焦。

双击图中节点或点击右侧“以此为中心”可查看局部上下游。点击关系可查看来源文件、行号、解析状态和
关系属性。左侧可按节点分类显示或隐藏节点，相关边会同步更新。虚线节点或关系表示项目外部目标或
未完全解析的依赖。
